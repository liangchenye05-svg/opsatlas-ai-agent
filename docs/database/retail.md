# 经营数据库

MySQL 8 数据库为 opsatlas，账户为 opsatlas_app。Flyway 管理版本。region、store、account、account_store 分别保存区域、门店、用户及店长授权，retail_order 和 retail_refund 保存经营明细。退款通过订单归属授权门店。

V2 是合成演示数据，包含两个区域、四家店、336 单。首次迁移基于 MySQL 当地星期一，初始化之前两周。徐汇店上周 42 单有 7 单退款，前周 42 单有 1 单退款。各订单金额由门店、日期和日内序号确定。真实金额与比率以 SQL 和 Java 测试的输出为准。

退款口径是统计期内下单、统计期末前已批准的退款。退款率分子为去重后的退款订单数。净额是销售额减退款金额。环比使用等长相邻区间，前期为零时返回 null，退款率变化以百分点计。
